Zero retention. The webhook URL and sender key are saved only on this phone. Each time you send, the text, this webhook URL and this sender key go to BUD's forwarder, which passes them straight to your bot and stores and logs none of them. The forwarder is run by CMDLAB on Cloudflare, which carries the traffic as the host. Your voice never goes through it.
